# Barcode Sticker Generator

Browser-first sticker serialisation and barcode/QR composition tool for VIVID product labels.

## V1 scope

- Upload a finished sticker artwork image.
- Set physical sticker size in millimetres.
- Place and resize a QR code, Code 128 barcode, and serial text over the artwork.
- Configure a unique prefix, serial digit count, start number, and quantity.
- Preview the first generated sticker live.
- Generate a serial range with validation.
- Export the serial list as CSV.

The project is intentionally frontend-first. A backend/database can be added later for shared batch history, duplicate prevention across devices, verification, and warranty activation.
